# REP Smith Machine reference photographs

Reference set for [issue #79](https://github.com/wesbos/gym-equipment/issues/79), harvested 2026-09-18 from REP's Shopify product JSON (`/products/<handle>.json`, largest variants, resizing parameters stripped) and the official overview video. Photos are REP Fitness product photography, not repository-authored artwork; their preservation here does not imply an open-source image license. The Altitude™ Smith (a different hook/safety design) was deliberately excluded.

Product pages: [REP® Smith Machine Rack Attachment](https://repfitness.com/products/smith-machine-rack-attachment) (`smith-machine-rack-attachment`), [Smith Machine Front Extension Bracket](https://repfitness.com/products/smith-machine-front-extension-bracket), [Front Foot Extension Pair 2.0](https://repfitness.com/products/front-foot-extension-pair-2-0).

Manuals (not committed; 8 MB / 49 MB): [Smith Machine Assembly Instructions Rev B, 45-010005-B](https://newrepcustomerfiles.blob.core.windows.net/publicfiles/Product/Assembly%20Instructions/Smith%20Machine%20Assembly%20Instructions%20(RevB).pdf) and [Smith Machine Configuration Guide, 45-010064-A](https://newrepcustomerfiles.blob.core.windows.net/publicfiles/Product/Assembly%20Instructions/Smith%20Machine%20Configuration%20Guide%20(with%20summit).pdf). Rev B page 2 lists the left/right *main structure assemblies* (ladder upright with guide rod, carriage and safety), the barbell assembly with welded hooks and the front-mount short crossmembers; page 3 lists upper (one hole + slot) and lower (two holes) L-brackets with M8 end-plate screws; steps 3–6 and 9–12 show the upright end plates seated on the L-bracket flange over the side crossmember / FFE.

`CDN` = `https://repfitness.com/cdn/shop/files/`.
